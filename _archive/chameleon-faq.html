Questions, answered

Short answers about how Chameleon works, which formats it supports and what happens to your files.

Getting started

What is Chameleon?

Chameleon is a file converter that adapts to whatever you drop in. It detects the file type, then shows only the formats and options that make sense for it, so an image gets image tools and a song gets audio tools.

Do I need an account?

No. Drop a file, choose a format and download the result. There is nothing to install and nothing to sign up for.

How do I convert a file?

Drop your file on the page or choose it from your device, pick the format you want, adjust the quality if you like, then press Convert. When it finishes, download the new file.

Files and formats

Which formats are supported?

Any format converts to any other format in the same family.

  • ImagesPNG, JPG, WEBP, GIF, SVG, AVIF, HEIC
  • AudioMP3, WAV, FLAC, AAC, OGG, M4A
  • VideoMP4, MOV, WEBM, MKV, AVI, GIF
  • DocumentsPDF, DOCX, TXT, RTF, EPUB, MD
What does the quality setting do?

Quality trades file size against detail. A lower setting gives a smaller file with some loss of detail, and a higher setting keeps more detail in a larger file.

Lossless formats such as PNG, WAV and FLAC ignore the setting.

Will I lose quality when I convert?

Converting to a lossy format such as JPG, MP3 or WEBP can discard detail, and converting back later will not restore it. Keep your original file if the quality matters to you.

What happens to transparency?

PNG, WEBP, AVIF and GIF can keep transparent areas. JPG cannot, so transparent areas are filled with a solid background colour. The hint under the format tiles tells you before you convert.

Troubleshooting

Why is my file not accepted?

Chameleon tells you when a file type is not supported and shows the formats that are. If the extension looks right, check that the file is not damaged or renamed from a different type.

A conversion is slow or failed. What can I do?

Large files and video take longer. If a conversion fails, try a lower quality setting or a different target format, then convert again.

If it keeps failing, contact us and include the file type and size.
